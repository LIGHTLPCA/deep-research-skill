## 🚀 Release Milestones

### 📍 v0.1.0 (Current Initial Release)
- [x] Multi-Hop Search Planner (4-vector query generator)
- [x] Async HTML Web Scraper & Clean Markdown Converter
- [x] Cross-Source Fact Auditor & Confidence Scoring
- [x] Executive Markdown Report Synthesizer with Inline Citations `[1]`
- [x] LIGHT LPCA BYOK Bridge & CLI Terminal Tool

- [ ] Direct PDF & DOCX export command flags (`--format pdf`)
- [ ] Streamlit/Gradio Web Playground interface

- [ ] Direct integration with local Ollama / vLLM endpoints for offline synthesis

## 🤝 How to Claim an Issue & Submit a PR

1. Browse open issues on our [GitHub Issue Tracker](https://github.com/LIGHTLPCA/light-lpca-deep-research/issues).
2. Comment on the issue: *"I would like to work on this!"*
3. Follow the instructions in [CONTRIBUTING.md](CONTRIBUTING.md) to set up your dev environment and submit a PR!
